# Paper drafts

Drafts of a software paper describing phu. Both are unfinished; items for the
authors are marked `TODO` inside each file.

- `gigabyte/manuscript.md`: Technical Release for GigaByte. The journal
  accepts Word or LaTeX, so convert before submitting.
- `joss/paper.md`, `joss/paper.bib`: the same content in the Journal of Open
  Source Software format.

Do not put unpublished project data, sample names or paths in these files.
Analyses reported in the paper must use public data.
